# Changelog

中文 | [English](#english)

## 中文

## AhaKey X1

### v1.1.0

- 发布 AhaKey X1 第一次大更新固件。
- 增加 USB HID 有线输入能力。
- 增加 USB / HID / 充电状态显示。
- 优化蓝牙 HID 未连接时的蓝灯提示。
- 优化蓝牙重置、蓝牙名称递增和重连状态处理。
- 三个主要模式的第 4 个键默认改为 Backspace。
- 调整默认灯光亮度。
- 增加 AI 状态灯效协议和亮度配置协议。
- 支持上位机通过 BLE / USB 进行关键配置同步。

### factory

- 发布 AhaKey X1 出厂固件。
- 作为蓝牙连接、基础键盘输入、默认屏幕和默认灯光体验的基线版本。

## English

## AhaKey X1

### v1.1.0

- Published the first major firmware update for AhaKey X1.
- Added USB HID wired input.
- Added USB / HID / charging status display.
- Improved Bluetooth HID disconnected blue-light indication.
- Improved Bluetooth reset, Bluetooth name increment, and reconnect handling.
- Changed the fourth key in the three main modes to Backspace by default.
- Adjusted default LED brightness.
- Added AI status light protocol and brightness configuration protocol.
- Added key configuration sync support over BLE / USB.

### factory

- Published AhaKey X1 factory firmware.
- Serves as the baseline firmware for Bluetooth pairing, keyboard input, default display, and default lighting behavior.
