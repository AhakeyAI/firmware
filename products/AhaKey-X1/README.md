# AhaKey X1 Firmware

中文 | [English](#english)

## 中文

这里存放 AhaKey X1 的官方可烧录固件和版本说明。

## 固件版本

| 版本 | 说明 | HEX |
|---|---|---|
| `factory` | 出厂固件。它是 AhaKey X1 基础蓝牙连接、基础键盘输入、默认屏幕和默认灯光体验的基石。 | [AhaKey-X1-factory.hex](releases/factory/AhaKey-X1-factory.hex) |
| `v1.1.0` | 第一次大更新。加入 USB HID、有线状态显示、蓝牙状态提示、AI 状态灯效协议、亮度配置、默认按键更新等能力。 | [AhaKey-X1-firmware-v1.1.0.hex](releases/v1.1.0/AhaKey-X1-firmware-v1.1.0.hex) |

## 如何选择

- 想恢复到最初出厂体验：使用 `factory`。
- 想测试当前稳定功能更新：使用 `v1.1.0`。
- 准备中的下一版功能请看 [drafts/](drafts/)，不要作为稳定固件烧录给普通用户。

## English

This directory contains official flashable firmware and release notes for AhaKey X1.

## Firmware Versions

| Version | Description | HEX |
|---|---|---|
| `factory` | Factory firmware. It is the baseline for AhaKey X1 Bluetooth pairing, keyboard input, default display, and default lighting behavior. | [AhaKey-X1-factory.hex](releases/factory/AhaKey-X1-factory.hex) |
| `v1.1.0` | First major update with USB HID, wired status display, Bluetooth status indication, AI status light protocol, brightness configuration, and default key updates. | [AhaKey-X1-firmware-v1.1.0.hex](releases/v1.1.0/AhaKey-X1-firmware-v1.1.0.hex) |
