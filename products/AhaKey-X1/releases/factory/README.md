# AhaKey X1 Factory Firmware

## 中文

这是 AhaKey X1 的出厂固件 HEX。

- AhaKey X1 出厂体验基线。
- 包含基础蓝牙连接、基础键盘输入、默认屏幕显示和默认灯光行为。
- 用于恢复出厂固件、对照测试和排查后续固件问题。
