# AhaKey X1 Firmware

这里用于说明 AhaKey X1 的官方固件版本、下载入口和烧录教程。

## 固件版本

| 版本 | 口径 | 推荐程度 | 下载 |
|---|---|---|---|
| v1.1.0 | 目前出厂会烧录的固件 / 当前推荐版本 | 推荐 | [AhaKey X1 Firmware v1.1.0](https://github.com/AhakeyAI/firmware/releases/tag/AhaKey-X1-v1.1.0) |
| v1.0.0 | 之前的老版本 | 仅旧版需要时使用 | [AhaKey X1 Firmware v1.0.0](https://github.com/AhakeyAI/firmware/releases#release-AhaKey-X1-v1.0.0) |

## 如何选择？

- 普通用户：选择 `v1.1.0`。
- 当前新出厂设备：使用 `v1.1.0`。
- 需要回到之前老版本行为：选择 `v1.0.0`。
- 不确定：优先选择 `v1.1.0`。

- HEX 文件统一放在 GitHub Releases。
